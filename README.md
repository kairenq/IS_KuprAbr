# 🎓 Информационная система "Студенческий актив"

Современная desktop-приложение для управления студенческим активом, разработанное на C# с использованием Windows Forms и SQLite.

## 📋 Описание

Информационная система "Студенческий актив" предназначена для учёта студентов, их распределения по группам и назначения ролей в студенческом активе (староста, заместитель старосты, физорг, культорг и др.).

## ✨ Основные возможности

- 🔐 **Система аутентификации** - регистрация и вход пользователей с хешированием паролей
- 👥 **Управление студентами** - добавление, редактирование и удаление информации о студентах
- 📚 **Управление группами** - учёт учебных групп с указанием факультета и курса
- 🎯 **Управление ролями** - назначение ролей студентам (староста, физорг и т.д.)
- 📖 **Инструкция пользователя** - встроенная справка в формате RTF/Word
- 💾 **SQLite база данных** - портативная локальная база данных
- 🚀 **Портативность** - работает с флешки без установки

## 🛠 Технологии

- **Язык**: C# 10
- **Платформа**: .NET 6.0
- **UI Framework**: Windows Forms
- **База данных**: SQLite 3
- **Библиотеки**:
  - System.Data.SQLite.Core 1.0.118
  - Dapper 2.1.28

## 🚀 Быстрый старт

### Требования

- Windows 7 или выше
- .NET 6.0 Runtime (для запуска) или SDK (для разработки)
- 50 МБ свободного места на диске

### Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone <repository-url>
   cd IS_KuprAbr
   ```

2. **Соберите проект**:
   - Запустите `Сборка.bat` (Windows)
   - Или используйте команду:
     ```bash
     cd StudentActiveSystem
     dotnet build -c Release
     ```

3. **Запустите приложение**:
   - Запустите `Запуск.bat` (Windows)
   - Или запустите напрямую:
     ```bash
     cd StudentActiveSystem/bin/Release/net6.0-windows
     ./StudentActiveSystem.exe
     ```

### Первый вход

При первом запуске используйте учётные данные администратора:
- **Логин**: `admin`
- **Пароль**: `admin`

> ⚠️ **Важно**: Рекомендуется сменить пароль администратора после первого входа!

## 📱 Использование

### Вход в систему

1. Введите имя пользователя и пароль
2. Нажмите кнопку "Войти"
3. Для новых пользователей используйте кнопку "Регистрация"
4. Для просмотра инструкции нажмите кнопку "📖 Инструкция пользователя"

### Управление студентами

1. Перейдите на вкладку "Студенты"
2. Используйте кнопки:
   - **Добавить студента** - создание новой записи
   - **Редактировать** - изменение существующей записи
   - **Удалить** - удаление записи
   - **Обновить** - обновление списка

### Управление группами и ролями

Аналогично управлению студентами, используя соответствующие вкладки.

## 🐛 Устранение неполадок

### Приложение не запускается

- Убедитесь, что установлен .NET 6.0 Runtime
- Проверьте, не заблокированы ли файлы антивирусом
- Попробуйте запустить от имени администратора

### Ошибка базы данных

- Проверьте наличие папки `Data`
- Убедитесь, что файл базы данных не заблокирован
- При необходимости удалите файл базы данных (он создастся заново)

### Не открывается инструкция

- Убедитесь, что в папке `Resources` есть файл инструкции
- Проверьте, что установлен Microsoft Word или совместимый редактор
